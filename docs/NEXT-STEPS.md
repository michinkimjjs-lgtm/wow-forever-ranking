# 다음 작업 우선순위 (2026-11-01 정리)

운영자와 합의한 다음 작업 순서입니다. 지금 사이트는 화면 미리보기(DEMO)는 갖췄지만, 실제 캐릭터 데이터는 아직 들어오지 않습니다(live·beta 영역의 게임 설정 미확정).

## 1순위. 실제 데이터를 받을 준비

| 할 일 | 막힌 이유 / 필요한 것 | 관련 문서 |
|---|---|---|
| 게임 설정 확정: 지역(region)과 게임 규칙(ruleset) 실제 값 | 확인 전에는 실제 랭킹 계산·등록을 열지 않음. 정식 출시·베타 클라이언트에서 실제 값 확인 필요 | `docs/RULESETS.md`, `config/game-scopes.ts` |
| 장비 기준(Gear Profile) 초안 | 포에버가 클래식 장비 칸(원거리 칸 포함)을 쓰는 것을 미리보기 작업에서 확인. 랭킹 대상 칸·양손 무기·빈 칸 처리를 `DRAFT`로 준비해 두고, 확인 후 `APPROVED` | `docs/GEAR-PROFILE.md` |
| Collector 애드온 실제 클라이언트 테스트 | 운영자가 게임에서 직접 실행해 확인 필요 | `docs/CONTRIBUTOR-GUIDE.md` |
| 웹 직접 등록 열기 | 위 설정·지역·직업 매핑 확인 후 | `docs/DATA-COLLECTION-STRATEGY.md` §2.5 |

## 2순위. 최초 달성 기록판

- 서버 최초 레벨 달성, 직업·진영·길드 최초 기록. 출시 직후 가장 많이 찾을 화면이며 사이트의 핵심 차별점.
- 공식 칭호(World First 등)는 `VERIFIED`·`LOG_VERIFIED` 기록에만 부여(명세서 §8.4, §23).
- 진행: 화면 미리보기(DEMO) 완료(2026-11-01, `/first-records`) → 실제 계산(`first_records`)은 데이터 연결 후.

## 3순위. 운영 안정성

- Vercel 연결을 프로젝트 소유 계정으로 다시 연결해 운영 오류 기록을 볼 수 있게 한다(2026-10-31 전체 화면 500 때 기록을 못 봐 원인 확인이 늦었음).
- 오류 알림(모니터링) 검토.

## 그 밖의 후보

- 랭킹 미리보기의 직업·진영·종족 필터 동작
- 캐릭터 장비 비교 화면
- 링크 공유 미리보기(Open Graph 이미지·문구) 다듬기
- 문의·제보 페이지
