# 제품 요구사항 (PRD) — Phase 1

> 기준 문서: `WOW_FOREVER_RANKING_SPEC.md`(v2), `CLAUDE.md`
> 이 문서는 Phase 1에서 실제로 구현된 범위와 동작을 정리한다.

## 1. 목표

WoW: Forever 전용 랭킹·Armory 사이트의 **실제로 동작하는 1차 버전**을 만든다.

- 외부 게임 데이터 API를 연결하지 않는다.
- **Mock 데이터만으로** 사이트 전체가 동작한다.
- 사용자에게 보이는 모든 화면은 **한국어**다.

## 2. 구현된 화면

| 경로 | 화면 | 주요 내용 |
|---|---|---|
| `/` | 홈 | KPI 5개, 최고 레벨 / 최고 장비 / 최고 아이템 Top 10, 최근 데이터가 갱신된 캐릭터, 최근 레벨이 상승한 캐릭터 |
| `/rankings/level` | 레벨 랭킹 | 순위, 캐릭터, 레벨, 직업, 진영, 길드, 마지막 확인, 검증 상태 |
| `/rankings/gear` | 장비 랭킹 | 순위, 캐릭터, 평균 장비 레벨, 최고 아이템, 직업, 진영, 길드, 마지막 확인 |
| `/rankings/highest-item` | 최고 아이템 | 순위, 캐릭터, 최고 아이템 레벨, 평균 장비 레벨, 아이템명, 직업, 진영 |
| `/characters` | 캐릭터 검색 | 이름 부분 일치 검색, 게임 모드 선택, 페이지네이션 |
| `/characters/{region}/{gameMode}/{slug}` | 캐릭터 Armory | 기본 정보, 현재 랭킹(또는 제외 사유), 레벨 달성 시각과 근거, 장비 슬롯 |
| `/guilds` | 길드 목록 | 길드명, 진영, 게임 모드, 캐릭터 수, 마지막 데이터 갱신 |
| `/guilds/{region}/{gameMode}/{slug}` | 길드 상세 | 길드명, 진영, 캐릭터 수, 대표 캐릭터, 최고 레벨, 최고 장비 레벨, 마지막 데이터 갱신, 길드원 목록 |
| `/stats` | 통계 | 준비 중 안내 |

상단 메뉴: 홈 · 랭킹 · 캐릭터 · 길드 · 통계.
던전 · 공격대 · World First는 "준비 중"으로 표시한다.

### Phase 1 프롬프트와 다른 점

캐릭터 / 길드 상세 URL은 프롬프트의 `/characters/[slug]`, `/guilds/[slug]` 대신 확정 설계(명세서 §7.6)를 따른다.

- 캐릭터: `/characters/{region}/{gameMode}/{slug}`
- 길드: `/guilds/{region}/{gameMode}/{slug}`

이유: 캐릭터 이름은 `(dataEnvironment, region, gameMode)` 안에서만 고유하다. 슬러그만으로는 캐릭터를 식별할 수 없다.

## 3. 랭킹 기능

- 필터
  - 환경(데이터 영역)
  - 게임 모드
  - 직업
  - 진영
  - 길드
  - 검증된 데이터만
  - 지역(지역이 2개 이상일 때만 표시)
- 서버 측 정렬과 페이지네이션(기본 50개, 최대 100개)
- 오래된 데이터 제외(최근 7일 이내 확인된 캐릭터만). 화면에 기준을 안내한다.
- 장비 / 최고 아이템 랭킹은 최소 장비 커버리지(랭킹 대상 슬롯의 75%)를 충족한 캐릭터만 포함한다.

자세한 규칙: [`RANKING-RULES.md`](./RANKING-RULES.md)

## 4. 데이터 상태 표시

- **Mock 안내**: 모든 페이지 상단에 항상 표시한다. 끌 수 없다.
  - 베타 테스트 데이터
  - 현재는 테스트 데이터가 표시되고 있습니다.
- **데이터 최신 시각**: `데이터 갱신: 2026년 10월 6일 오후 3:42 · 마지막 확인: 2분 전` (KST)
- **검증 상태**: 검증됨 / 로그 검증 / 사용자 제출 / 미검증 / 테스트 데이터
- **상태 문구**: 7일 이상 확인되지 않은 캐릭터는 "현재 랭킹 제외", 장비가 부족하면 "장비 정보 부족", 계산 기준이 없으면 "계산 기준 확인 중"으로 표시한다.

## 5. 이번 단계에서 하지 않은 것

- Blizzard OAuth / API 연동
- Raider.IO, WOWF.IO API 연동
- 외부 사이트 스크래핑
- 던전 / 공격대 / World First 실제 연동
- 사용자 제출, 애드온 수집 (P1)
- 통계 화면, 성장 그래프 (P1). 데이터(`character_snapshots`, `level_milestones`)는 이미 저장한다.
- Redis, BullMQ (P1). 지금은 캐시 인터페이스와 인메모리 구현만 있다.
